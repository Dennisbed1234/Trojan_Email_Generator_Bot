# Email Generator Telegram Bot

A Telegram bot that generates email
addresses for software testing and dataset generation.

## Features

- Generate up to 1,000,000 records
- Random first names
- Random last names
- Randomized email patterns
- TXT export
- CSV export
- JSON export
- SQLite user settings
- Configurable `.test` domain
- Streaming generation
- Does not require storing 1 million emails in RAM

## Requirements

Python 3.10+
